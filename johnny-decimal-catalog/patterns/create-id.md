# Create a new ID

**Use when** a note or folder needs a number that does not exist yet.

## Steps

1. Pick the **category** (`CC`) for the subject. If none fits, that is an owner
   decision — do not invent a category.
2. List the existing items in that category and find the **highest used content ID**.
3. The new ID is the next **usable** number: start at `.11`, and **skip any number
   ending in `0`**. So `.11`, `.12` … `.19`, `.21` … `.29`, …
4. Never reuse a retired ID. Never renumber existing IDs.
5. Name the item `CC.NN-Short-Name` (folders) or `CC.NN-Short-Name.md` (notes).

## Key rules

- Content starts at `.11`; `.00–.09` are the standard zeros.
- `.06`, `.07`, `.08` are reserved — never allocate them.
- `A0` categories are management; `10` is not a content category.
- Numbers are permanent. A rename changes the name, never the number.

## Example

Category `12` already has `12.11`–`12.15`. The next item is `12.16` (any zero-ending
number is skipped only if it would land on one, e.g. after `12.19` comes `12.21`).
